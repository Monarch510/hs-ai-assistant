# 05 原型聚类：单链改平均连接，止住「A~B、B~C 但 A≁C」的串味

> 优先级：P2（学习链路）
> 规模：单模块（`hsai/meta.py`），一个 AI 独立可完成
> 前置阅读：`docs/plan/00-现状.md` §4.4、§5.10、§7
> 基线：`Ran 160 tests … OK`；本机 `data/meta/` 18 个原型、`observations.jsonl` 178 行

## 1. 目标

`meta.build_from_observations()` 的簇合并判据从「与簇内**任一**样本相似」改为「与簇内样本**平均**相似」，使「A 像 B、B 像 C、但 A 不像 C」的三套牌不再被并成一簇（模板只剩中间那套的牌，A 和 C 永远学不出来）。

可验收：新增 `tests/test_clustering_average.py` 全绿（同一组数据：旧实现 1 簇、新实现 2 簇）；`tests/test_learn.py`、`tests/test_naming.py`、`tests/test_meta_store.py` **一行不改**且通过；`python -m hsai meta rebuild --dry-run` 能跑完并记录前后原型数量。

## 2. 背景

- **00 §5.10**：聚类算法有两个已知弱点（暂未修）——单链聚类会「串味」；两个变体各占一半时模板变成并集。
- **AGENTS 坑（原型库）**：明确写了修复顺序「**单链 → 平均连接 → 签名加局数下限 → 超 30 张报警**」。后两项**已经落地**：`min_games`（`meta.py:400,443`）与 `DECK_MAX_CARDS` 整簇放弃（`meta.py:456-459`）；只剩第一项没做。
- **00 §4.4**：聚类入口 `meta.build_from_observations()`（`meta.py:396-485`），阈值 0.34；单链实现就是 `sim = max(_jaccard(sample, other) for other in cluster)`（`meta.py:433`）。
- 串味的真实信号（AGENTS）：同职业两个原型覆盖率差老是 0–8%、或某个原型超过 30 张。修完必须用真实数据看一眼（见验收 5.3）。

本任务**不是**重写聚类：不引入第三方库、不改阈值、不改命名/`content_id`/存储格式。

## 3. 涉及文件

### 3.1 `build_from_observations()`（`meta.py:396-485`）

- 把聚类循环（`428-439`）里的单链判据改成平均连接：
  ```python
  sim = sum(_jaccard(sample, other) for other in cluster) / len(cluster)
  ```
  注释写清为什么：「单链会让 A~B、B~C 但 A≁C 的三套牌变成一簇，签名只剩中间那套的牌」。**选一种口径并固定**（建议「与簇内已有样本的平均相似度」），不要引入 UPGMA 的加权变体。
- 保持不变：`threshold=0.34` 默认值、样本按输入顺序处理、`clusters.sort(key=len, reverse=True)`、`min_games` 过滤、衍生物过滤（`cards.is_token`）、`signature` 的 50% 规则、`DECK_MAX_CARDS` 放弃规则、`pick_key_cards` + `_name_archetype` 命名、`prior = len(cluster)/total`。
- 不改 `save()` / `load()` / `_load_dir()` / `_migrate()` / `content_id()` / `import_archetypes()` —— 这些属于存储与外部导入，不在本任务。

### 3.2 `tests/test_clustering_average.py`（新增）

用 `hsai.cards.load()` 的 WARRIOR 标准牌池取 10 张互不相同的牌，按下面构造三个样本（**用索引取牌，别写死卡牌 id**）：

```
A = {a1, b1, b2}        # a1 只在 A 出现
B = {b1, b2, b3, b4}
C = {b3, b4, c1}        # c1 只在 C 出现
J(A,B) = 2/5 = 0.40 ≥ 0.34
J(B,C) = 2/5 = 0.40 ≥ 0.34
J(A,C) = 0
```

- `observations = [{"opp_class": "WARRIOR", "revealed": A}, {... B}, {... C}]`，`min_games=1`，`threshold=0.34`。
- 断言：旧实现（单链）会把三者并成 1 簇，新实现 `len(meta) == 2`；且存在一簇含 `a1`、另一簇含 `c1`（用 `a.cards` 判断，**不要**断言原型名）。
- 回归用例：三个**完全相同**的样本 → 仍然是 1 簇（平均连接不能把该合的拆开）。
- 回归用例：阈值不传时默认仍是 0.34（用两个 J=0.35 左右的样本，断言合并）。
