## 收尾时我改的两处（06 的测试文件）

**1. `_texts()` 只认假 tkinter**

```python
opts = getattr(c, "_opts", None)      # 真 tkinter 控件没有这个属性
```

Windows 自带 tkinter 8.6，`_ui_support.install()` 不会装替身，于是同一组用例
**在 CI 上绿、在开发机上红**。加了 `cget("text")` 兜底。

**2. 分差用例注入的值被 tick 冲掉**

`root.update()` 会执行 Overlay 启动时排进 `after` 队列的 `_tick`（替换 `_tick`
属性拦不住那个已绑定的方法）。它拿真实 demo 状态又渲染一遍，把测试注入的
`_ai_pick` / `_pick_gap` 清成 None。
测试里同时 patch 掉 `_maybe_ai` 和 `_update`。
