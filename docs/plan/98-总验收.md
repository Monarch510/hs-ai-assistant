## 3. 语义冲突（自评查不出来的三处）

单份全绿不代表合起来对。这三处必须**用真实日志回放**看行为，不是看测试。

### 3.1 01 → 02：牌库分母变了

```powershell
python -m hsai replay <一份真实 Power.log> | Select-String "deck_count"
```

- 我方与对方的 `deck_count` **应不同**（以前双方都是 `30 − 我方抽牌`）
- 对方牌库数随回合递减，且 **不会突然跳成 0 或负数**
- 再跑 `python -c "from hsai import cards,state,advisor;..."` 取一局快照，确认 `prediction` 的候选概率之和仍约等于 1

### 3.2 03 → 02/06：权重清掉后分值断言还成立吗

- 03 删的是「恒为 1」的僵尸权重；确认 `model.DEFAULT_WEIGHTS` 里**不再有**那个键
- 但 02/06 的测试里有断言具体分差（例如 `opp_fast` 加 0.8、`gap` 展示）
- 判定：**跑 02/06 的专项测试**，如果它们因为权重表变化而红，说明 03 动到了语义，不是「清理」——打回 03

### 3.3 05 → 04：聚类口径变了，校准样本数会变

```powershell
python -m hsai meta rebuild --dry-run
```

- 记录重建前后的原型数量
- 05 的目标是「止住 A~B~C 串味」，**预期原型数变多**（一个簇拆成两个）
- 但 `meta rebuild` 会改 `truth.arch` 对应关系：确认 04 的 `meta calibrate` 报告里**样本数不为 0**（为 0 说明 id 又漂了，和 AGENTS 那条坑冲突）
