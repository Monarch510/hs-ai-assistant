# 炉石传说 AI 助手（本地 / 只读日志 / 原生悬浮窗）

一个跑在自己电脑上的炉石副驾：**一个无边框、始终置顶的原生窗口**，读游戏日志，
告诉你对面可能是什么卡组、这回合怎么打。

- 纯 Python 标准库（含 tkinter），无第三方依赖，不联网（只有首次下载卡牌库）
- **不注入输入、不改客户端**，只读 `Power.log`
- 没有浏览器、没有本地端口、没有黑框：双击就是一个悬浮窗

---

## 一键启动

双击 **`启动AI助手.bat`**，或者：

```powershell
python -m hsai ui          # 悬浮窗（默认）
python -m hsai ui --demo   # 用示例对局演示，不接游戏
```

第一次运行会自动下载卡牌库（约 10 MB，含衍生物/英雄技能）。之后完全离线。

### 窗口怎么用

| 操作 | 效果 |
|---|---|
| 按住顶部拖动 | 移动窗口（位置会记住） |
| 右键 | 透明度、字号、收起/展开、退出 |
| `F8` | 全局显示/隐藏 |
| 关闭按钮 `×` | 退出 |

不在对局时，窗口会自己缩成一条 28px 的细条；新对局开始自动展开。

## 面板上是什么

```
T7 · 我方回合 · 对手 死亡骑士        对局中
┌ 对手预判 ─────────────────── 核心 ┐
│ 节奏战                        82% │   ← 没有证据时这里显示「未识别（可能是新卡组）」
│ ▓▓▓▓▓▓▓▓▓░░░                      │
│ · 已出现 血帆海盗 → 节奏战（标志牌 ×2）│
│ ! 5 费：绝命乱斗 [清场]            │
└───────────────────────────────────┘
┌ 本回合建议 ───────────────── 决策 ┐
│ ① 用 寒冰箭 打 暴乱狂战士 → 共 2 步 88│
│    打残 暴乱狂战士 剩 1 血；解掉它   │
│ ② 或者：打出 工程师学徒          71 │
└───────────────────────────────────┘
```

- **对手预判**：卡组名 + 置信度 + 依据（最多两条）+ 下回合威胁（最多两条）
- **留牌建议**：只在起手出现，逐张给「留/换 + 分数 + 一句理由」
- **本回合建议**：1–3 条路线，第一条是推荐；出现红色横幅就是能斩杀
- **一行风险提醒**：清场概率、斩杀线这类「看了场面才知道」的警告

场面、候选条形图、日志流、网页版——都没有了（按你的要求删掉了）。

## 卡组代码导入（让预判真的能用）

预判要靠「已知卡组库」。库里默认只有十几个示例原型，**不包含当前环境**——
我也不会编 2026 年的卡组。所以需要你把主流的几套喂进去，一次就够：

```powershell
# 在游戏里：收藏 → 选中卡组 → 复制（得到 AAEC... 一串）
python -m hsai deck add "AAECAf0EB...=="      # 加入对手卡组库
python -m hsai deck mine "AAECAf0EB...=="     # 登记自己的卡组（留牌建议靠它）
python -m hsai deck show                      # 看看现在登记了什么
```

导入时会打印解出来的每一张牌，**你能一眼看出解错没解错**（张数不对会拒绝入库）。

> 没有卡组库时，预判会老实显示「未识别（可能是新卡组）」，而不是随便猜一个还给 100%。
> 这是我特意改的行为：之前它对死亡骑士只有一个候选，所以看到什么都报满分，那是假自信。

## 让游戏写日志

工具靠 `Power.log`。它装在**客户端目录**（不是 `%LOCALAPPDATA%`）时，日志也在那边：

```
D:\software\Hearthstone\Logs\Hearthstone_2026_10_31_12_09_15\Power.log
```

启动脚本会自动检查并在缺少时写入 `log.config`（有备份）。手动执行：

```powershell
python -m hsai setup-log
```

写完必须**完全退出游戏再启动**才生效。启动脚本还会提示日志是不是太久没更新。

## 命令

```powershell
python -m hsai ui [--demo] [--log PATH]   # 悬浮窗
python -m hsai ui --check                 # 只做环境检查
python -m hsai setup-log                  # 写入 log.config
python -m hsai deck add|mine <卡组代码>    # 卡组代码导入
python -m hsai cards --update             # 更新卡牌库
python -m hsai log                        # 终端里跟日志（不看窗口时）
python -m hsai replay <日志文件>           # 离线解析，输出快照 JSON
python -m hsai mulligan WARRIOR 寒冰箭 火球术   # 离线测留牌
python -m hsai meta list|build|import|calibrate
python -m hsai sim 节奏法 控制战 --trace   # 自对弈
python -m hsai learn [--games 4] [--force] # 自对弈调权重（带留出验证）
python -m hsai stats
```

## 已知限制

1. **独占全屏下悬浮窗压不上去**。炉石里要选「窗口化」或「无边框窗口」。
2. **卡组库要靠你喂**（见上）。空库时预判只报「未识别」。
3. 卡组效果解释器只认常见文本（伤害/抽牌/BUFF/消灭/召唤），认不出的牌会降权处理。
4. 对手手牌内容看不到，只能给概率——这是规则决定的。
5. 只支持常规对战；酒馆战棋、竞技场选牌、佣兵不解析。
